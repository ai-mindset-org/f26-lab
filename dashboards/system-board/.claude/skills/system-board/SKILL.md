# system-board

цель: страница http://127.0.0.1:8981/ показывает свежий день системы; режим показа без личного.
готово: `node check.mjs` пишет «ok», в `data-show.json` ноль личных слов, в `runs.md` новая строка.

вход: только чтение – папки из `config.json` (агенты, правила, skills, волты), экспорт Telegram, если указан.

шаги (из папки дашборда):
1. нет `config.json` → скопируй `config.example.json`, заполни пути вместе с человеком
2. Telegram указан и есть доступ к чатам → обнови файл сообщений за сегодня; нет доступа → пропусти шаг
3. `python3 collect.py && python3 collect.py --show`
4. порт 8981 не слушает → `python3 -m http.server 8981 --bind 127.0.0.1` в фоне
5. `node check.mjs` → «ok»; снимки в `/tmp/codex-screenshots/system-board`
6. приватность: `grep -c` по `data-show.json` на имена людей и слова из сегодняшних разговоров → везде 0
7. открой снимок вкладки «сегодня» и посмотри глазами: подписи не наезжают, ни одна фигура не пустая
8. строка в `runs.md`: дата · сессии / заметки / skills · что поправить
9. ответ: адрес показа http://127.0.0.1:8981/, полный режим `?full` – только на этой машине

если цифра странная (0 сессий, пустой ряд) – сначала источник в `collect.py` и путь в `config.json`, страницу не трогать.
никогда: запись в систему, `data.json` или `config.json` в git, `?full` на общем экране.

эталон: `demo/data.json` – та же схема на вымышленных данных.
