# онтология · связи

| поле | от | к | смысл |
|---|---|---|---|
| `with` | встреча, решение | человек | кто участвовал |
| `project` | встреча, решение, человек | проект | к чему относится |
| `from_meeting` | решение | встреча | где решили |
| `source` | встреча, заметка | сырьё | откуда факт |
| `parent` | контекст | self | срез чего |
| `owner` | проект | человек | кто отвечает |

Связь пишется ссылкой в поле frontmatter: `with: "[[{person} Nina]]"`. Агент ставит связь, когда создаёт файл; висячая ссылка на графе – пунктир, план на следующую сущность.
