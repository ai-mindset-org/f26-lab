# уровни доступа

У каждого файла поле `access`. Уровень решает, кто видит файл и что агент с ним делает. Без поля файл считается T1.

| уровень | что | пример | агент |
|---|---|---|---|
| **T0** публичное | то, что уже открыто миру | [[{identity} about me]], люди лабы с сайта | читает и цитирует |
| **T1** рабочее | кто я, чем занят, как работаю | [[self]], `context/`, проекты, решения | читает на старте |
| **T2** адресное | выбранное для конкретного человека | self для тройки, отчёт собственнику | показывает только адресату |
| **T3** личное | дневник, отношения, личные деньги | `private: true`, письма себе | не читает без просьбы в этой сессии |
| **T4** уязвимое | здоровье, терапия, данные других людей | в папку агента не кладётся | видит только указатель в описи |

## как поставить
```
access: T2
```
`private: true` равен T3. Повышать уровень можно без вопроса, понижать – только человек.

## откуда
Пять уровней взяты из протокола личного контекста ведущего лабы: T0 публичное · T1 командное · T2 партнёрское · T3 личное · T4 уязвимое, открывается только после явной просьбы.
