# папка {{name}} · self-harness

Папка, в которой агент знает, кто я. В центре `self.md`, вокруг – всё, что агент читает, чтобы работать со мной без пересказа. Папка растёт четыре недели лабы F26 вместе со мной.

## шаг ноль

Открой агента в этой папке и спроси: «кто я и что делаю на этой неделе?». Ответ по файлам, с названиями файлов. Где агент угадал – там следующая правка.

## четыре недели

1. **собрать** – self.md, правила, сырьё, имена, онтология, уборка.
2. **научить** – повторяемая работа становится скиллом.
3. **отпустить** – рутина работает сама, у каждой бюджет и проверка.
4. **пользоваться** – одна точка входа, недельный обзор пишет агент, self.md учится по обзорам недели.
