# имена файлов

Агент находит файл по имени раньше, чем открывает его. Имя отвечает на три вопроса: что это, о чём, когда.

```
{тип} Описание – ГГГГ-ММ-ДД.md
```

- **тип** в фигурных скобках: `{context}` `{rule}` `{person}` `{project}` `{decision}` `{meeting}` `{note}` `{raw}` `{draft}` `{skill}` `{routine}` `{eval}` `{dashboard}` `{tool}`. Полный список с полями – [[{ontology} types]].
- **описание** – о чём, с именем человека или проекта.
- **дата в конце** у снимков: встреча, решение, черновик, обзор. У живых файлов (человек, проект, правило) даты нет.
- центр папки без типа: `self.md`, `AGENTS.md`, `CLAUDE.md`, `README.md`.

| было | стало |
|---|---|
| `Новый документ (3).docx` | `{draft} закупки на декабрь – 2026-11-09.md` |
| `звонок.txt` | `{raw} call transcript supplier – 2026-11-06.md` |
| `how-i-decide.md` | `{context} how-i-decide.md` |

Старые файлы руками не переименовываю. Агент составляет список «было → стало», я подтверждаю целиком, ссылки правятся в том же коммите.
