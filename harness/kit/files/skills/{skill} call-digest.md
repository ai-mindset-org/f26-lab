# call-digest

после звонка: расшифровка → встреча, решения, люди.

1. возьми расшифровку из `raw/`
2. создай `{meeting}` с полями `with`, `project`, `source` по [[{ontology} links]]
3. решение – отдельный `{decision}` с причиной и отвергнутым вариантом
4. новый человек – `{person}` только с ролью, без личных данных
5. письмо по итогам – черновик по [[{rule} drafts before sending]]

**выход:** 1 встреча, 0–3 решения, ссылки на людей и проект

Правила папки – [[AGENTS]].
