# правила агента в этой папке

Агент читает этот файл на старте каждой сессии. Пять правил. Правлю, когда агент делает не то.

1. **на старте** прочитай [[self]].
2. **куда класть.** Сырьё – `raw/`, разобранное – `notes/`, черновики – `drafts/` с датой в имени. Новых папок не создавай, спроси меня.
3. **как называть.** Тип, описание, дата в конце: правило появится в [[{rule} naming]].
4. **что не трогать.** Ничего не удаляй и не переименовывай без моего «да». Никому ничего не отправляй. Границы – [[{rule} boundaries]].
5. **в конце** назови файлы, которые тронул.
