    01 · скачать движок

    репозиторий лабы открыт: github.com/ai-mindset-org/f26-lab ↗. нужны git и Node.js 18+ (brew install git node). без git – архив набора ↓, движок в папке harness/.

    git clone https://github.com/ai-mindset-org/f26-lab.git ~/f26-lab
    02 · развернуть свою папку

    new.sh собирает папку по 12 фазам – 12 коммитов за пару секунд – и открывает граф на localhost:4747. существующую папку не перезаписывает. следующий запуск – bin/open.sh ~/self.

    ~/f26-lab/harness/bin/new.sh ~/self
    открыть localhost:4747 ↗если граф уже запущен; при занятом 4747 open.sh берёт следующий порт и пишет адрес в терминале

    другой пример вместо Марии: new.sh ~/self personal-os · small-firm-owner · own-product · alex (ведущий лабы) · свои ответы: new.sh ~/self --answers my.json

    03 · открыть папку в Finder и Obsidian

    Finder: open ~/self. Obsidian: «Open folder as vault» → ~/self, один раз; дальше кнопка Obsidian в карточке файла открывает файл сразу. ссылки [[…]] кликаются, граф Obsidian показывает ту же онтологию.

    04 · первый разговор с агентом
    cd ~/self && claude

    спроси: «кто я и что делаю на этой неделе?» – ответ по файлам, с названиями файлов. потом «проведи self-интервью по skills/» – и пример Марии становится твоим. Codex читает тот же AGENTS.md: cd ~/self && codex.

    без терминала · папка в браузере

    выбери свою папку контекста или перетащи её сюда из Finder: граф строится из файлов, правки сохраняются прямо в них. агенты, сессии и коммиты – в полном режиме выше. на телефоне папку не выбрать.

    Chrome, Arc, Edge
