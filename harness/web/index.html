    01 · папка в браузере

    выбери свою папку контекста на компьютере или перетащи её сюда из Finder. граф строится из файлов, правки сохраняются прямо в них. без установки; агенты, сессии, откат и коммиты – в полном режиме. на телефоне папку не выбрать: подключай с компьютера.

    Chrome, Arc, Edge
    02 · полный режим: агенты, сессии, откат, форк, Obsidian

    в терминале: скачать движок в новую папку (нужны git и Node.js 18+):

    git clone https://github.com/ai-mindset-org/f26-lab.git ~/f26-lab

    создать свою папку и открыть граф. Для следующего запуска: bin/open.sh ~/self. Существующую папку new.sh не перезаписывает:

    ~/f26-lab/harness/bin/new.sh ~/self
    открыть localhost:4747 ↗если граф уже запущен; при занятом 4747 open.sh берёт следующий порт и пишет адрес в терминале

    своя папка с нуля: ~/f26-lab/harness/bin/new.sh ~/self · копия с историей: ~/f26-lab/harness/bin/fork.sh ~/self ~/self-try · остановить: ~/f26-lab/harness/bin/stop.sh [порт] · нет gh: brew install gh && gh auth login
