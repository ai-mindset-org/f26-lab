# эстафета skills · игра тройки

Каждый ставит на старт один skill. Двое соседей по очереди меняют в нём одну вещь под свой контекст и передают дальше. Палочка возвращается к владельцу с двумя правками и двумя взглядами на его работу, и он решает, какие принять. Круг занимает 20 минут и доигрывается в чате тройки без ведущего.

## как сыграть

Скажи своему агенту в папке `f26-lab`:

> запусти игру тройки

Агент прочитает `GAME.md`, спросит ник и стол и поведёт по ходам. Без агента те же ходы делает страница:

```
python3 games/trio-swap/table.py serve <стол>
```

| ход | время | что делает человек | что делает агент |
|---|---|---|---|
| старт | 3 мин, можно до встречи | выбирает один skill, читает карточку и палочку, говорит «да» | собирает список skills, делает копию без имён и путей, запускает проверку |
| этап 1 | 5 мин | даёт свой вход, выбирает одну правку | отвечает на три вопроса к чужому skill, примеряет его как текст, заполняет поля |
| этап 2 | 5 мин | то же с палочкой второго соседа | то же и проверяет результат прошлого бегуна |
| финиш | 5 мин на тройку | принимает или отклоняет каждую правку, читает цепочку вслух | показывает цепочку версий и предлагает внести принятое в настоящий skill |

## стол: три способа

- **git** – репозиторий тройки, команды с ключом `--git`.
- **общий стол** – один запускает `table.py serve <стол> --share`, двое открывают ссылку в браузере.
- **файл** – `table.py pack` после хода, файл в чат, сосед делает `table.py unpack`.

Заготовка стола лежит в `table/`.

## что защищает игру

1. Палочка – один текстовый файл до 60 строк. Скрипты, вложения и скрытые файлы в стол не попадают.
2. Проверка останавливает палочку с почтой, телефоном, ключом, путём с именем пользователя, скрытым комментарием, невидимым символом, фразой в обход человека и действием без подтверждения. Удаление, отправку, сеть, установку программ и доступ к сервисам она показывает списком фактов.
3. Чужую палочку никто не ставит в папку skills: агент примеряет её как текст на данном входе.
4. Этап меняет до 8 строк, имя палочки меняет только владелец, каждая версия записана с хэшем. Правку мимо стола видно сразу.
5. Перед записью в стол человек видит файл целиком.

Проверка ловит небрежность. Имена людей и компаний и хитро спрятанную команду ловит человек, который читает 60 строк глазами.

## что лежит в папке

| файл | зачем |
|---|---|
| `GAME.md` | инструкция агенту: правила, ходы, транспорт |
| `SKILL.md` | skill игры для Claude Code и Codex |
| `table.py` | стол: что делать сейчас, проверка, запись этапов, страница |
| `web/` | страница эстафеты |
| `templates/` | карточка, этап, финиш |
| `table/` | заготовка стола для новой тройки |
| `example/` | круг синтетической тройки и лог прогона |
| `chat.txt` | текст в чат комнаты до начала игры |

## ведущему

1. За день: у каждой тройки есть стол и способ (git, общий стол или файл). Текст из `chat.txt` ушёл в чаты троек.
2. До встречи: каждый поставил палочку на старт. Старт занимает три минуты и проходит без соседей.
3. На встрече: закрыть круги, 5 минут этап 1, 5 минут этап 2, 5 минут финиш в тройках, по одной цепочке вслух в общем зале.
4. После: тройка, которая не успела, доигрывает в своём чате. `table.py next <стол> <ник>` говорит каждому, чей ход.
