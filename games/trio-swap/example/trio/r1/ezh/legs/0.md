# call-digest

**вход:** заметка или расшифровка созвона, строки с номерами L1, L2…
**готово, когда:** каждое обещание из входа лежит в одной из двух секций, у каждой строки номер из входа.

## шаги
1. найди фразы-обещания: кто-то что-то сделает
2. есть кто и срок – строка в «обязательства»
3. чего-то нет – строка в «уточнить», пустое поле: «не указан»
4. обсуждение без обещания не выписывай

## выход
```
обязательства
L1 · Аня · список вопросов · до 19.11
уточнить
L3 · Вера · пункты в план недели · срок: не указан
```

## никогда
- не додумывай срок и владельца
- ничего не отправляй: результат – черновик

## проверка
у каждой строки номер из входа · тот же вход дважды – тот же результат · заметка без обещаний – обе секции пустые
