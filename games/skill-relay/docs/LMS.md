# эстафета skills в LMS

Стол один, инструментов два. **Веб-платформа** живёт на своём адресе: широкий экран, стадион, полная история. **Версия для LMS** стоит на странице лабы: одна колонка под ширину LMS, цвета и шрифты LMS. Журнал у них общий. Переключателя между ними нет: вид задаёт адрес.

| что | адрес игры | кто видит |
|---|---|---|
| веб-платформа | `<адрес игры>/` | тот, у кого есть сессия игры |
| версия для LMS | `<адрес игры>/lms/` | рамка на странице лабы |
| карточка для правой колонки | `<адрес игры>/card` | все, без имён участников |
| макет размещения | `<адрес игры>/lms-preview` | для сверки вида, LMS в нём нарисована |

## как встаёт в LMS

Размеры взяты из `aim-lms`, `src/layouts/Layout.tsx`.

| место | ширина | что стоит |
|---|---|---|
| правая колонка | 208–288 px, скрыта уже 1024 px | карточка под компасом |
| средняя колонка | до 860 px, до 1060 px на широком экране; на экране 1440 выходит около 790 px, на 1024 около 450 px | страница `/f26/relay` с рамкой игры |

1. **Карточка.** Родной компонент LMS по образцу `LabCompassCard`: статичный рисунок, ссылка на `/f26/relay`. Образец: `docs/lms/SkillRelayCard.tsx`. В `Layout.tsx` карточка ставится сразу после `LabCompassCard`, на своей странице скрыта. Карточка сама спрашивает функцию, включена ли игра, и рисуется только тогда.
2. **Страница.** Маршрут `/f26/relay` под `ProtectedRoute tier="user" labId="f26"`. Внутри одна рамка с игрой. Образец: `docs/lms/SkillRelayPage.tsx`, клиент функции и разбор сообщения высоты: `docs/lms/skill-relay.ts`.
3. **Функция входа.** Проверяет токен участника и лабу, просит у игры одноразовую ссылку и отдаёт её странице вместе с адресом игры: по нему страница принимает сообщения высоты. `GET ?lab=f26` отвечает, включена ли игра. Образец: `docs/lms/skill-relay-enter.ts`.
4. **CSP LMS.** В `frame-src` добавить адрес игры: в `deploy/nginx.conf` (его отдаёт сервер LMS) и в `netlify.toml` для паритета. Без него браузер рамку не покажет.

Всё включается двумя серверными переменными LMS: `SKILL_RELAY_URL` и `SKILL_RELAY_MINT_SECRET`. Переменных сборки нет. Без них карточки нет, страница пишет «игра пока не включена». Образцы в `docs/lms/` повторяют запрос на правку в репозитории LMS.

Карточку можно поставить и рамкой `<адрес игры>/card`: она живая, показывает дорожки и число версий. Родной компонент проще: ему не нужна рамка в правой колонке.

## вход

```
страница LMS  →  POST /.netlify/functions/skill-relay-enter   (токен участника)
функция LMS   →  POST <адрес игры>/api/mint                    (X-Mint-Secret)
                 {"tg_id": "…", "username": "…", "display_name": "…", "source": "lms"}
игра          →  {"authorized": true, "auth_link": "<адрес игры>/auth/complete?token=…", "ttl": 900, "surface": "lms"}
страница LMS  →  ставит auth_link адресом рамки
игра          →  ставит сессию и открывает /lms/
```

- `tg_id` обязателен: по нему игра узнаёт человека. Ссылка живёт 15 минут и срабатывает один раз.
- В журнале вход записан как «вход: LMS», у каждой версии стоит имя участника.
- Имя и ник приходят из аккаунта LMS. На столе сверху стоит строка «ты за столом как Имя · @ник · вход: LMS». Пустые имя и ник в составе дополняются при входе, записанное раньше имя вход не переписывает.
- Состав лабы проверяет LMS. Игру на сервере запускают с `--open`: она пускает каждого, кого привела функция LMS, файл состава не нужен.
- Сессия игры лежит в cookie `SameSite=Lax`. LMS и игра стоят на одном сайте (`aimindset.org`), в рамке cookie передаётся.
- С той же сессией человек открывает веб-платформу в новой вкладке: ссылка «на весь экран» внизу версии для LMS.
- «Встать из-за стола» в версии для LMS возвращает skill на стол и оставляет вход; кнопка «вернуться за стол» стоит на том же экране. Выход совсем закрывает сессию игры, следующий вход снова идёт через LMS.

## высота рамки

Версия для LMS сообщает странице высоту содержимого:

```js
window.parent.postMessage({ type: 'skill-relay:height', height: 1297 }, '*')
```

Страница LMS проверяет `event.origin` и ставит рамке эту высоту. Своей прокрутки у рамки нет. Карточка `/card` шлёт `skill-relay:card-height`.

## переменные игры

| переменная | значение |
|---|---|
| `RELAY_FRAME_ANCESTORS` | кому можно показать `/lms/` и `/card` рамкой: адрес LMS и адрес её стенда через пробел, например `https://learn.aimindset.org` |
| `RELAY_LMS_LINK` | адрес страницы эстафеты в LMS: туда ведут карточка и кнопка «войти через LMS» |
| `RELAY_MINT_SECRET` | общий секрет с функцией LMS |
| `RELAY_PUBLIC_URL` | адрес игры, с него строится `auth_link` |

Страницы веб-платформы отдаются с `frame-ancestors 'none'`: рамкой встаёт только `/lms/` и `/card`.

## проверка перед включением

1. `<адрес игры>/lms-preview` показывает версию для LMS в сетке LMS: ширины 1728, 1440, 1024 и телефон.
2. На стенде LMS рамка открывается у участника лабы, в журнале игры запись «вход: LMS».
3. Участник не из лабы получает от функции `not_in_lab`, рамка не открывается.
