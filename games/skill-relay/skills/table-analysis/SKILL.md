# анализ таблицы: от вопроса к проверенному числу

Уровень 3 · тема «данные». Нужен запуск кода на файле.

## вход

Файл или таблица и вопрос. Если вопроса нет («посмотри данные»), сделай только шаги 1–2 и спроси, на какой вопрос отвечать.

## параметры

| параметр | по умолчанию | что значит |
|---|---|---|
| инструмент | Python с pandas | чем считать |
| срез | все строки | период или фильтр, заданный человеком |
| точность | 1 знак после запятой, доли в процентах | округление в ответе |
| минимальная группа | 5 строк | группы меньше не показываются отдельно |
| объём | до 200 слов и одна таблица | размер ответа |
| график | нет | строить ли один график к главному выводу |

Если рядом с этим файлом лежит `params.md`, значения из него заменяют умолчания.

## шаги

Порядок менять нельзя: вывод, посчитанный до профиля данных, чаще всего стоит на грязном столбце.

- [ ] 1. **Профиль.** Число строк и столбцов, типы, доля пропусков по столбцам, дубликаты по ключу, диапазон дат, пять случайных строк. Результат покажи таблицей.
- [ ] 2. **Сомнительные места.** Выпиши всё, что может исказить ответ: смешанные форматы дат, числа текстом, единицы в одном столбце, итоговые строки внутри данных. По каждому реши: чинить, исключить или спросить.
- [ ] 3. **Вопрос как расчёт.** Перепиши вопрос формулой: что делим на что, по каким группам, за какой период. Покажи формулу человеку одной строкой, если в вопросе были слова «средний», «рост», «конверсия»: у них несколько определений.
- [ ] 4. **Расчёт кодом.** Считай только кодом. Числа, прикинутые в уме по выведенным строкам, в ответ не идут.
- [ ] 5. **Сверка.** Выполни обе проверки из раздела «проверка». Не сошлось: вернись к шагу 2.
- [ ] 6. **Вывод.** Ответ на вопрос, числа, способ расчёта, оговорки. По шаблону.

Не переходи к следующему шагу, пока текущий не отмечен.

## формат вывода

```
Ответ: <одна-две фразы с главным числом>

| группа | значение | строк в группе |
|---|---|---|
| … | … | … |

Как считал: <формула словами, фильтры, что исключено и сколько строк>
Оговорки: <пропуски, малые группы, сомнительные столбцы>
Что проверить дальше: <один следующий вопрос к данным>
```

## проверка

1. **Итог сходится.** Сумма по группам равна общему итогу, посчитанному отдельно. Число строк после фильтров равно исходному минус исключённые.
2. **Вторым способом.** Главное число пересчитано другим путём (другая функция или ручной пересчёт на 10 строках) и совпало.

## грабли

- Среднее от средних по группам не равно среднему по всем строкам: группы разного размера. Считай от исходных строк.
- Дата `03.04` читается как 3 апреля или 4 марта в зависимости от выгрузки. Проверь по значению больше 12 в первой позиции.
- Пропуск и ноль это разные значения. Перед расчётом среднего посмотри, чем заполнены пустые ячейки.
- Запятая как разделитель дробной части превращает число в текст, и столбец молча выпадает из суммы.
- После фильтра «только активные» в данных остаются те, кто дожил до выгрузки. Вывод о всех по ним делать нельзя.

## никогда

- Не показывай в ответе строки с персональными данными. Примеры строк приводи без столбцов с именами, контактами и идентификаторами.
- Не выводи отдельным рядом группу меньше параметра «минимальная группа»: объединяй в «прочие».
- Не меняй исходный файл. Очистка идёт в копии или в памяти.
- Не называй причину («просело из-за …»), если данные показывают только совпадение по времени. Пиши «совпадает с».
