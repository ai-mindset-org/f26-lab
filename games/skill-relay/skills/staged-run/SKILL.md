# длинная задача по этапам

Уровень 5 · тема «оркестрация». Нужны запись файлов и запуск исполнителей (сабагенты, отдельные сессии или последовательный режим в одном окне).

## вход

Задача и признак готовности: что должно существовать и работать в конце. Без признака готовности спроси его одним вопросом.

## параметры

| параметр | по умолчанию | что значит |
|---|---|---|
| папка состояния | `run/` рядом с работой | где лежат план, брифы и журнал |
| исполнителей одновременно | 2 | сколько кусков идёт параллельно |
| срок жизни куска | 10 минут без файла на диске | когда кусок считается зависшим |
| бюджет | 12 кусков на задачу | после него остановка и вопрос человеку |
| подтверждение | удаление, отправка наружу, запись в общие данные, оплата | перед чем спрашивать человека |
| формат отчёта | список «сделано · чем проверено · где лежит» | вид итога |

Если рядом с этим файлом лежит `params.md`, значения из него заменяют умолчания.

## файлы состояния

```
run/PLAN.md      цель, признак готовности, куски со статусом
run/briefs/NN.md бриф куска, после запуска не меняется
run/LOG.md       одна строка на событие: время, кусок, что произошло
run/DONE.md      итоговый отчёт
```

## шаги

- [ ] 1. **Продолжение или начало.** Если `run/PLAN.md` существует, прочитай его и `run/LOG.md` и продолжи с первого незакрытого куска. Нового плана поверх старого не пиши.
- [ ] 2. **План.** Запиши цель, признак готовности и куски. У куска есть вход, проверяемый выход и пометка «независимый» или «после NN».
- [ ] 3. **Показ плана.** Покажи план человеку, если в нём есть действия из параметра «подтверждение» или кусков больше восьми.
- [ ] 4. **Брифы.** На каждый независимый кусок напиши бриф по шаблону. Бриф закончен до запуска: правка после старта перезапускает работу и теряет сделанное.
- [ ] 5. **Запуск.** Независимые куски отдай исполнителям, не больше параметра одновременно. Куски с общим файлом идут по очереди. Вид, компоновку и всё, что требует смотреть глазами, делай сам.
- [ ] 6. **Приёмка куска.** Проверь результат сам: файл существует, выход совпадает с брифом, проверка из брифа проходит. Слова исполнителя «готово» приёмкой не считаются.
- [ ] 7. **Журнал.** После каждого события допиши строку в `run/LOG.md` и статус в плане.
- [ ] 8. **Сборка.** Собери куски, прогони признак готовности целиком.
- [ ] 9. **Отчёт.** Запиши `run/DONE.md` по шаблону и покажи человеку.

## шаблон брифа

```
Цель: <что должно существовать после куска>
Вход: <файлы и факты, пути целиком>
Уже исключено: <что проверено и не подошло>
Границы: <что не трогать>
Выход: <файл и его вид>
Проверка: <команда или признак, по которому видно, что готово>
```

## формат отчёта

```
Готово: <признак готовности> · <да | частично | нет>

| кусок | что сделано | чем проверено | где лежит |
|---|---|---|---|

Не сделано: <кусок и причина>
Ждёт человека: <действия из «подтверждение»>
Найдено по дороге, не чинилось: <список>
```

## когда остановиться

- Потрачен бюджет кусков: остановись, покажи журнал и спроси, продолжать ли.
- Кусок провалился дважды с одним брифом: не запускай третий раз, разберись в причине сам.
- Исполнитель молчит дольше срока жизни куска и на диске нет его файла: считай кусок зависшим и забери работу себе.
- Впереди действие из параметра «подтверждение»: остановись и спроси.

## проверка

- В `run/PLAN.md` нет куска в статусе «идёт».
- У каждой строки отчёта заполнено «чем проверено».
- Признак готовности проверен командой или просмотром в этом же запуске.
- Обрыв сессии на любом шаге оставляет файлы, по которым работу можно продолжить.

## грабли

- Два исполнителя правят один файл, и второй затирает первого. Общий файл принадлежит одному куску.
- Исполнитель получает гипотезу и возвращает её подтверждённой. В брифе пиши вопрос и то, что уже исключено.
- План в голове исчезает при сжатии контекста. Источником правды служит файл плана.
- Параллельность ускоряет только независимые куски. Три исполнителя на цепочке из трёх шагов тратят втрое больше и ждут друг друга.

## никогда

- Не выполняй действие из параметра «подтверждение» без ответа человека в этой сессии. Старое разрешение из журнала не считается.
- Не останавливай и не закрывай чужие процессы и сессии.
- Не отдавай исполнителю секреты и данные людей шире, чем нужно для его куска.
