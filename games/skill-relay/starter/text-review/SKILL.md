# оценка текста по критериям

Уровень 3 · тема «оценка». Один проход, без инструментов.

## вход

Текст и задача текста: кто читатель и что он должен сделать после чтения. Если задача не названа, определи её по тексту, назови первой строкой и попроси поправить, если ошибся.

## параметры

| параметр | по умолчанию | что значит |
|---|---|---|
| критерии | ясность, польза для читателя, структура, доказательность | по чему оценивать |
| шкала | от 1 до 5 | оценка по каждому критерию |
| правки | три | сколько правок назвать |
| строгость | редактор перед публикацией | насколько придирчиво читать |

## шаги

1. Прочитай текст целиком глазами читателя из задачи. Запиши, где остановился, где заскучал и где не поверил.
2. Пройди по критериям по одному. К каждой оценке приведи строку текста, на которой она стоит.
3. Собери замечания и отсортируй по влиянию на задачу текста. Опечатки и вкусовые замены идут в конец.
4. Выбери правки по параметру. Правка называет место, что с ним сделать и как это изменит текст для читателя.
5. Назови одно сильное место, которое при правке нужно сохранить.
6. Сверь результат по разделу «проверка» и отдай.

## проверка

- У каждой оценки есть строка из текста.
- Правок столько, сколько задано в параметрах.
- Замечания относятся к тексту и не оценивают автора.
