# эстафета skills

Открытая беговая эстафета для группы от 5 до 30 человек. На дорожках лежат пять skills. Участник входит под своим логином, берёт свободный skill, примеряет его на своей задаче, вносит одну правку по правилу из гайдов, получает разбор и передаёт skill дальше. У каждого skill счётчик передач: видно, сколько раз он прошёл через руки.

Соседняя игра `games/trio-swap` рассчитана на тройку, которая знает друг друга. Здесь состав открытый: число участников заранее неизвестно, порядок никто не назначает.

## правила

1. **Вход.** У каждого свой логин. В живом режиме вход по одноразовой ссылке из бота, в демо достаточно сесть на свободное место.
2. **Взять.** Свободная дорожка закрывается за тобой на 20 минут. В это время skill скачиваешь и правишь только ты.
3. **Примерить.** Skill приходит как текст. Ты запускаешь его у своего агента на своей задаче и смотришь, где он спотыкается.
4. **Одна правка.** Разбор предлагает три правила, по которым правка даст больше всего. Ты выбираешь одно и меняешь до 12 строк.
5. **Разбор.** Модель читает «было» и «стало» и отвечает на четыре вопроса: правило применено, skill остался общим, личного в тексте нет, остальное цело.
6. **Передать.** Версия с разбором уходит следующему. Замечание разбора видно в цепочке дорожки.
7. **Пауза.** После взятия час паузы на все дорожки. Свою прошлую правку подряд не продолжают.

Не успел за 20 минут: skill возвращается на старт без правки, пауза остаётся.

## запуск

Нужен Python 3.9 или новее. Сторонних пакетов нет.

```
python3 relay.py init  ./stol --demo        # стол с демо-составом и первыми передачами
python3 relay.py serve ./stol --demo        # http://localhost:8996
```

В демо «час» идёт 7 минут, skill держится за человеком 5 минут, по дорожкам бегут восемь ботов с заготовленными правками (25 штук в `demo/patches.json`). Флаг `--lan` открывает страницу в локальной сети, `--bots 0` убирает ботов.

У сервера три страницы и журнал:

| адрес | что там |
|---|---|
| `/` | стадион: вход, дорожки, забег, цепочка версий |
| `/show` | прогон: один круг из 12 шагов в трёх окнах участников. Каждое действие настоящее и идёт на отдельном столе `<стол>/.show`, основной стол прогон не меняет. Клавиши `→` `←`, `A` ведёт сам, `R` сначала, `?step=7` открывает шаг |
| `/rules` | книга: 19 правил с практикой и первоисточником, настройка skill в харнессе, замеры. Якоря `#G-07`, `#settings`, `#evidence`, `#sources` |
| `/?view=log` | журнал стола: кто действовал, через что (страница, агент, бот, система) и как вошёл |

Прогон разбирает правки по признакам, поэтому шаг отвечает сразу и одинаково при каждом показе. На самом столе правки разбирает модель.

Живой режим:

```
python3 relay.py init ./stol
export RELAY_SESSION_SECRET=$(openssl rand -hex 32)
python3 relay.py serve ./stol --live --public-url https://<адрес>
python3 relay.py mint  ./stol --login <ник> --name "<имя>" --public-url https://<адрес>
```

Команда `mint` печатает одноразовую ссылку входа на 15 минут и вписывает человека в состав. Бот выдаёт такие же ссылки сам через `POST /api/mint`: порядок в `docs/DEPLOY.md`.

Разбор моделью включается переменной `OPENROUTER_API_KEY`. Модель задаёт `RELAY_REVIEW_MODEL` (по умолчанию `anthropic/claude-sonnet-5.5`), дневной потолок вызовов `RELAY_REVIEW_CAP` (400). Без ключа игра идёт на признаках из `relay.py`, и страница пишет «признаки без модели».

При группе больше 15 человек пяти дорожек мало: `init --heats 2` кладёт по два экземпляра каждого skill.

## что лежит в папке

| путь | что это |
|---|---|
| `relay.py` | стол, вход, сервер, проверка текста, разбор |
| `skills/` | пять базовых skills: саммари, исследование, анализ таблицы, записка для решения, длинная задача по этапам |
| `guides/rules.json` | 19 правил развития skills: вопрос, правка, практика и первоисточник; настройка skill в харнессе (`settings`) и замеры (`evidence`) |
| `guides/RULES.md` | те же правила для чтения, собирается командой `relay.py rules` |
| `guides/sources.json` | 12 гайдов, 3 исследования и 7 библиотек skills, по которым собраны правила |
| `GAME.md` | инструкция агенту участника: как бежать этап поверх своего харнесса |
| `web/` | стадион (`index.html`), прогон по шагам (`show.html`), книга правил (`rules.html`) |
| `demo/patches.json` | заготовленные правки для ботов |
| `docs/check.py` | проверка пайплайна: 70 шагов, с `--model` ещё пять с настоящим разбором и запиской от модели |
| `docs/DEPLOY.md` | размещение, вход через бота, состав, место в LMS |

Оригиналы гайдов в репозиторий не входят. Команда `python3 relay.py guides` скачивает их в `guides/raw/` для чтения агентом.

## что записывает стол

`lanes/<skill>/SKILL.md` хранит текущую версию, `lanes/<skill>/legs/NNN.md` и `NNN.json` хранят каждую передачу с правилом, записками, разбором и отпечатком версии, `lanes/<skill>/RELAY.md` показывает цепочку таблицей, `TRAIL.md` ведёт общий след, `events.jsonl` хранит журнал построчно: время, кто, что, дорожка, через что. В `NNN.json` у каждой передачи записано, от чьего лица она сделана: `via` (правку прислала страница или агент), `agent` (какой харнесс), `passed` (кто нажал передачу), `auth` (способ входа). С флагом `--git` каждая передача становится коммитом в репозитории стола.

## безопасность

- Skill в игре остаётся текстом. Установка у себя происходит по решению человека после чтения.
- Проверка текста останавливает передачу, если в ней почта, телефон, ключ, путь с именем пользователя, скрытый комментарий, невидимые символы, закодированный блок или фраза в обход человека.
- Имена людей и компаний проверка текста не видит. Их ловит разбор модели и человек, который читает правку.
- Тексты уходят модели как данные в разделителях. В запросе нет имён участников и состава.
- Страница вставляет чужой текст только как текст. Сервер сверяет Host и Origin, принимает JSON до 64 КБ и отдаёт строгую политику содержимого.
- Сессия живёт в cookie с флагами HttpOnly и SameSite=Lax, за https добавляется Secure и префикс `__Host-`.
