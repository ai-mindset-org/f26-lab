# от идеи к согласованному замыслу

Уровень 3 · тема «замысел». Разговор в несколько ходов. По мотивам brainstorming из obra/superpowers.

## вход

Идея словами человека и то, что уже есть по теме: файлы, заметки, прошлые попытки.

## параметры

| параметр | по умолчанию | что значит |
|---|---|---|
| вопросов за ход | один | сколько вопросов задавать сразу |
| вариантов | два или три | сколько подходов предлагать |
| часть показа | до 200 слов | размер куска замысла на согласование |
| куда | файл замысла рядом с работой | где лежит итог |

Если рядом с этим файлом лежит `params.md`, значения из него заменяют умолчания.

## шаги

1. Посмотри, что уже есть по теме, до первого вопроса.
2. Выясни цель, ограничения и признак успеха. Один вопрос за ход, по возможности с вариантами ответа.
3. Предложи два или три подхода с ценой каждого и назови свой выбор.
4. Покажи замысел по частям. После каждой части спроси, верно ли это.
5. Запиши согласованный замысел в файл.
6. Спроси, готов ли человек перейти к плану работ.

## формат вывода

```
Цель: <одна фраза>
Ограничения: <пункты>
Признак успеха: <как поймём, что получилось>
Подход: <выбранный вариант и почему>
Части: <по абзацу на часть>
Открытые вопросы: <пункты или «нет»>
```

## грабли

- Человек отвечает «да, всё так» на длинный кусок и теряет несогласие в середине. Короткие части ловят его раньше.
- Первый подход кажется единственным. Второй вариант часто меняет саму постановку задачи.
