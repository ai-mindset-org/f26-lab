# собрать свой skill

Уровень 5 · тема «skill». Длинная работа в несколько этапов. По мотивам skill-creator из anthropics/skills.

## вход

Работа, которую человек делает повторно: разговор, где она уже сделана, или описание словами. Для доработки: существующий файл SKILL.md.

## параметры

| параметр | по умолчанию | что значит |
|---|---|---|
| объём | до 150 строк | верхняя граница файла навыка |
| проверочных задач | три | сколько задач готовить для прогона |
| куда | папка skills харнесса человека | где лежит результат |
| язык | язык запроса | язык текста skill |

Если рядом с этим файлом лежит `params.md`, значения из него заменяют умолчания.

## шаги

### 1. понять работу

Выясни у человека, что именно должен делать навык, в каких случаях инструкция должна включаться и что считается хорошим результатом. Если работа уже сделана в разговоре, возьми её шаги оттуда и попроси человека подтвердить. Агент хорошо умеет писать тексты и код, поэтому общие советы вроде «пиши понятно» в навык не идут.

### 2. написать черновик

Шапка состоит из name и description. В description напиши, что делает skill и когда его брать, словами, которыми человек об этом просит. Тело навыка: вход, шаги, формат вывода. Пиши в повелительном наклонении. Объясняй причину требования: агент лучше следует инструкции, смысл которой понимает.

### 3. прогнать

Придумай проверочные задачи: запросы, которые человек задаст на самом деле. Прогони инструкцию на каждой. Покажи человеку результаты рядом.

### 4. доработать

Собери замечания человека. Правь навык по замечаниям: одно замечание, одна правка. Обобщай: правка под одну задачу ломает остальные. Повтори прогон.

### 5. уточнить описание

Проверь, включается ли skill на нужных запросах. Если агент его пропускает, допиши в описание слова из пропущенных запросов.

## формат вывода

```
<имя skill>/
  SKILL.md
```

К файлу приложи одну строку: на каких задачах проверен и что осталось сырым.

## проверка

- В шапке есть name и description, description отвечает «что делает» и «когда брать».
- Файл укладывается в объём.
- Каждая проверочная задача прогнана после последней правки.

## грабли

- Описание пересказывает шаги. Агент читает такое описание вместо тела и пропускает шаги.
- Навык растёт от каждого замечания и превращается в свалку частных случаев.
