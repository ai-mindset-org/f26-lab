# передача дел новому агенту

Уровень 2 · тема «контекст». Один проход по разговору. По мотивам handoff из mattpocock/skills.

## вход

Текущий разговор целиком и файлы, которые в нём менялись.

## параметры

| параметр | по умолчанию | что значит |
|---|---|---|
| объём | одна страница | верхняя граница записки |
| читатель | агент, который разговора не видел | для кого записка |
| куда | файл `handoff.md` рядом с работой | где лежит результат |

Если рядом с этим файлом лежит `params.md`, значения из него заменяют умолчания.

## шаги

1. Назови цель работы одной фразой, словами человека.
2. Перечисли сделанное: что изменено и где это лежит.
3. Выпиши решения и причину каждого. Отвергнутые варианты тоже запиши, чтобы их не предлагали заново.
4. Выпиши ограничения человека дословно.
5. Назови следующий шаг так, чтобы его можно было начать без вопросов.
6. Сохрани записку и покажи человеку путь к ней.

## формат вывода

```
Цель: <одна фраза>
Сделано: <пункты с путями>
Решения: <решение – причина>
Ограничения: <дословно>
Следующий шаг: <одно действие>
```
