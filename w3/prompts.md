# промпты недели 3

Те же промпты, что в разделе «путь задачи» на странице вечера: https://f26-w3.lab.aimindset.org/#path. Вставлять в Claude Code или Codex, открытый в своей папке. Каждый промпт – один разговор.

## 1. карта решений: где решал я

Открой последнюю сессию над одной задачей и вставь:

```text
Пройди по этой сессии. Найди мои ходы, где я принимал решение. Для каждого: что выбрал, что отбросил, почему. Нарисуй карту решений деревом. Отметь решения, которые я принимаю каждую неделю: их можно записать правилом.
```

## 2. повтор → правило

```text
Вот решение, которое я принимаю каждую неделю: …
Запиши его одной строкой в правила проекта (CLAUDE.md или AGENTS.md), чтобы в следующей сессии ты делал это без меня. Покажи строку до записи.
```

## 3. правило → расписание

```text
Сделай из этого одну команду, которая работает без меня и пишет результат в файл. Предложи расписание и строку журнала на каждый запуск: время, статус, что сделал. Напиши, как остановить.
```

## 4. паспорт перед расписанием

```text
Помоги заполнить паспорт рутины по routine.md из набора w3: владелец, вход, skill, один планировщик, время с часовым поясом, условие запуска, что делает сам, что только с моего «да», предел, куда пишет, проверка, как остановить, когда смотрю журнал, дата пересмотра.
Спрашивай по одному полю, к каждому свой рекомендованный ответ. Пока я не сказал «ставим», ничего не устанавливай и не запускай по расписанию.
```
