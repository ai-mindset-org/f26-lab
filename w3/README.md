# воркшоп 3 · отпустить · материалы

F26 · Fall Lab · AI Mindset · пн 23.11.2026. Найти в своей сессии, где решал ты, что повторяется каждую неделю, и отдать этот повтор правилу, команде и расписанию. Каждый запуск оставляет строку журнала.

| слой 3 харнеса | https://f26-harness.lab.aimindset.org/?layer=3 | пять фаз, пять блоков, три петли и журнал на графе папки |

## за пять минут

Нужны git, Node.js 18+ и Claude Code или Codex.

```bash
git clone https://github.com/ai-mindset-org/f26-lab.git ~/f26-lab   # или git pull, если уже есть
cd ~/f26-lab/w3/routine
./run.sh --demo                        # цепочка без агента: ответ из examples/, проверка, журнал, экран
./run.sh --demo --input input/empty.md # пустой вход: ответ обязан сказать «нет данных»
./run.sh                               # настоящий прогон: claude -p; AGENT=codex ./run.sh – через Codex
open status.html                       # экран: нужна ли моя помощь
```

Дальше всё то же на своей задаче: свой `SKILL.md`, свой вход в `input/`, свои правила в `check.mjs`.

## 1. путь задачи

Пять блоков любой автоматизации: **когда** (триггер) → **что** (правило, skill или промпт) → **кто и где** (агент) → **что осталось** (журнал) → **где видно** (экран). Пять фаз задачи, у каждой свой след:

| фаза | вопрос | след |
|---|---|---|
| 1 · разбираюсь | что хочу и что уже есть? | заметка: цель и вход |
| 2 · ясно | что делаем и как пойму, что вышло? | пять строк: цель, вход, выход, проверка, срок |
| 3 · делаю с агентом | выходит ли руками? | два ручных прогона |
| 4 · работает само | что происходит без меня? | строка журнала на каждый запуск |
| 5 · пересматриваю | оставить, поправить, руками или выключить? | одно решение недели |

Три петли контроля: **ход агента** (минуты, смотришь карту решений) → **запуск** (дни, смотришь журнал и экран) → **пересмотр** (неделя, смотришь дерево решений).

## 2. кандидат

Порог: от 48 минут в неделю. Четыре часа на сборку (два прогона, skill, проверка, паспорт) окупаются за пять недель лабы. Задача, где ошибка стоит денег или доверия, остаётся с тобой: агент готовит, решаешь ты. Повтор находит промпт «карта решений» в [`prompts.md`](prompts.md).

## 3. два прогона и три входа

`run.sh` делает один проход: читает вход, зовёт агента со `SKILL.md`, отдаёт ответ в `check.mjs` и пишет строку в `run-log.csv`. Проверка кодом одинакова каждый раз: три строки, у каждой источник `[N1]`, во входе есть все даты и дни недели из ответа. Если самая свежая заметка старше двух дней, ответ обязан это сказать.

Три входа в `input/`:

- `notes.md` – обычный: две заметки о проекте;
- `empty.md` – пустой: верный ответ «нет данных», любой другой текст означает, что агент выдумал;
- `old.md` – старый: ответ начинается со строки «вход устарел».

Прогон не прошёл – одна правка правила в `SKILL.md`, второй прогон, оба остаются в журнале.

## 4. паспорт

[`routine/routine.md`](routine/routine.md): колонка примера и пустая колонка для своей рутины. Без владельца и стопа рутину не ставим. Стоп у набора один для всех способов запуска: файл `STOP` рядом с паспортом, `run.sh` видит его и записывает запуск как `stopped`.

## 5. где поставить расписание

Один планировщик на рутину. Время ставь на :07, запуск ровно в :00 часто задерживается.

| способ | где работает | что нужно | где журнал | как остановить |
|---|---|---|---|---|
| launchd + `run.sh` | свой мак; спящий догонит запуск при пробуждении | `./launchd/install.sh` | `run-log.csv`, `status.html` | `touch STOP` или `./launchd/install.sh --remove` |
| задача в Claude Desktop | свой мак, пока приложение открыто | Code → Scheduled → New task → Only on this computer | страница задачи | пауза там же |
| облачная задача Claude | серверы Anthropic, мак может быть выключен | `/schedule` в Claude Code, репозиторий на GitHub; не чаще раза в час | страница задачи: Succeeded значит «сессия закончилась», результат проверяй сам | выключатель на странице задачи |
| задача Codex | приложение ChatGPT desktop или веб | раздел Scheduled, проект, режим local или worktree | раздел Scheduled | пауза там же |
| GitHub Actions | GitHub, без мака | [`routine/github/morning-brief.yml`](routine/github/morning-brief.yml), секрет ключа в репозитории | вкладка Actions и `run-log.csv` в репозитории | `routine/STOP` или Disable workflow |

Для запуска без тебя вход в Claude Code держится ограниченное время. Для долгих задач по расписанию Claude Code советует `claude setup-token`. Расписание в публичном репозитории GitHub отключается после 60 дней без активности.

## 6. журнал и экран

`run-log.csv` хранит факты: `run_id, started_at, input, mode, status, check, next_action`. `status.mjs` превращает последнюю строку в четыре поля `status.json`:

```json
{ "source": "run-log.csv", "updated_at": "…", "status": "ok | needs_attention | error | stopped | silent", "next_action": "…" }
```

и собирает `status.html`: вопрос «нужна моя помощь?», четыре поля, полоса последних запусков. Если журнал молчит дольше 26 часов, статус становится `silent`: рутина умерла тихо. Сторожа снаружи можно добавить одной строкой: сервис вроде healthchecks.io ждёт пинга после каждого успешного запуска и пишет, если пинг не пришёл.

## 7. неделя: семь записей до 30.11

Каждый запуск, ошибка или пропуск – строка журнала. К 30.11 их семь. По ним одно из четырёх решений: оставить, поправить, вернуть в ручной запуск, выключить. Сбой становится строкой правила в `SKILL.md` или `AGENTS.md`. Рутина, которой неделю никто не хватился, кандидат на выключение.
