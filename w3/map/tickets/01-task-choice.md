# Какую задачу отдаю

## Question
Какую повторяющуюся задачу отдаю рутине первой?

## Done when
Задача одной строкой, вход и результат названы, тест «станет ли хуже, если запускать руками» пройден.

## Answer
Утренний обзор справочника: две заметки → три строки. Руками хуже: по утрам я забываю открывать заметки.

## Consequence
Рутина нужна, дальше ищем источник.
