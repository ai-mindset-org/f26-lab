# утренняя сводка

Вход: заметки проекта, каждая начинается с `[N1, дата]`.
Выход: ровно три строки и больше ничего.

```
сделано: … [N…]
мешает: … [N…]
следующий шаг: … [N…]
```

Правила
- у каждой строки в скобках номер заметки, из которой это взято
- даты и дни недели – только те, что есть во входе; чего во входе нет, пишу «неизвестно»
- вход пуст – одна строка: «нет данных: вход пуст. следующий шаг: проверить источник»
- самая свежая заметка старше двух дней – перед тремя строками строка «вход устарел: <дата заметки>»
- ничего не отправляю и не меняю, только пишу ответ
