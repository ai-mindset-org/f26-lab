# трасса сессии · как думает и работает твой агент

Страница читает журнал сессии Claude Code или Codex на твоём компьютере и по ходу работы показывает, где агент ищет, формулирует, делает, проверяет, зовёт тебя и отпускает работу другим.

```bash
cd ~/f26-lab/w3/trace
python3 trace.py serve          # открой http://127.0.0.1:8997/session.html?follow=new
claude                          # в любой другой папке: страница подключится к новой сессии сама
```

Нужен только Python 3. Сервер слушает 127.0.0.1, журналы никуда не уходят. Без сервера `session.html` открывается двойным кликом и показывает учебную запись.

## что на странице

- **холм хода:** точка идёт вправо, когда агент перестаёт искать и начинает делать; кружок с вопросом – ждёт тебя;
- **дорожки:** каждый шаг агента – отметка в своей дорожке, рыжая отметка – сбой команды, вертикаль – твоя реплика;
- **дерево ходов:** твой вопрос → какие шаги и файлы → чем кончилось: решено, ждёт тебя, в работе;
- **сейчас:** последний шаг, последняя мысль агента, шаг, который агент назвал сам («шаг 3 · делаю»).

Дорожки считаются по инструментам: чтение и поиск – «ищу», запись планов, брифов, SKILL.md и мысли – «формулирую», запись кода и команды – «делаю», тесты, снимки и проверки – «проверяю», запуск других агентов и расписаний – «отпускаю», вопрос тебе – «зову человека». Правила в `trace.py`, их можно поменять под себя.

## запись своей сессии

```bash
python3 trace.py list                                   # последние сессии обоих агентов
python3 trace.py export <id или файл.jsonl> --anon > my.json
```

`--anon` убирает тексты реплик и мыслей, остаются инструменты и имена файлов. Файл открывается кнопкой «файл записи».

Журналы лежат в `~/.claude/projects/<папка>/<id>.jsonl` и `~/.codex/sessions/ГГГГ/ММ/ДД/rollout-*.jsonl`.
