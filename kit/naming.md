# имена файлов

Агент находит файл по имени раньше, чем открывает его. Хорошее имя отвечает на три вопроса: что это, о чём, когда.

```
{тип} Описание – ГГГГ-ММ-ДД.md
```

- **{тип}** – одно слово в фигурных скобках: встреча, решение, заметка, план, отчёт, идея, письмо. Скобки отличают тип от описания, агент и поиск находят все файлы одного типа.
- **описание** – о чём, с именем человека или проекта.
- **дата в конце** – когда создано. Сортировка по дате остаётся, поиск по смыслу тоже.

| было | стало |
|---|---|
| `Новый документ (3).docx` | `{план} Закупки на декабрь – 2026-11-09.md` |
| `звонок.txt` | `{встреча} Нина про поставщиков – 2026-11-06.md` |
| `идеи!!!.md` | `{идея} Отчёт собственнику агентом – 2026-11-09.md` |

Старые файлы не переименовывай руками. Попроси агента составить список «было → стало» и подтверди его целиком.

Особые файлы без даты: `self.md`, `AGENTS.md`, `CLAUDE.md`, `log.md`, `README.md`. Их имена знает любой агент.
