# одно подключение · только чтение

MCP – способ дать агенту доступ к источнику: календарю, заметкам, почте. На первой неделе хватит одного источника и только на чтение. Ключи и токены в папку контекста не клади.

## Claude: приложение и claude.ai

Настройки → Connectors → Google Calendar или Notion → подключить. Ключ не нужен. Права проверь в окне подключения.

## Claude Code

```
claude mcp add --transport http notion https://mcp.notion.com/mcp
claude mcp list
```

Вход откроется в браузере. Проверка: в сессии `/mcp`, затем «покажи три последние страницы Notion, ничего не меняй».

## Codex

Файл `~/.codex/config.toml`, пример в `codex.config.toml` рядом.

## LMS лабы

Ключ агента в кабинете https://learn.aimindset.org/cabinet. По ключу агент получает список встреч, расшифровки в markdown и чат эфира, только чтение. Выгрузи расшифровки нужных встреч в `raw/` и ищи по ним.
