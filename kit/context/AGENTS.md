# правила для агента в этой папке

<!-- пять правил. Агент читает этот файл на старте каждой сессии. Правь его, когда агент делает не то. -->

1. **на старте** прочитай `self.md`, потом последние строки `log.md`.
2. **куда класть.** Сырьё – в `raw/`, разобранное – в `notes/`, черновики – в `drafts/` с датой в имени. Новых папок не создавай, спроси меня.
3. **как называть.** `{тип} Описание – ГГГГ-ММ-ДД.md`, например `{встреча} Закупки с Ниной – 2026-11-09.md`. Правило в `naming.md`.
4. **что не трогать.** Ничего не удаляй и не переименовывай без моего «да». Никому ничего не отправляй. Файлы с пометкой `private` не читай.
5. **конец сессии.** Допиши в `log.md` одну строку: дата, что сделал, что осталось.
